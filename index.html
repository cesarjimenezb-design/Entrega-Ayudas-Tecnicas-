Bodega / FIN700 · Stock
La consulta de stock gobierna el flujo de consumo, lista de espera, traspaso y compra.
FIN700 es un sistema externo (ERP), no un módulo de este sistema. Cuando no existe stock local para una indicación, ésta queda en estado Lista de Espera y este sistema envía una solicitud de artículos (traspaso o compra) a FIN700 mediante webservice. FIN700 responde por sistema despachando los artículos solicitados y esa respuesta abastece el stock local, liberando las indicaciones en lista de espera.
